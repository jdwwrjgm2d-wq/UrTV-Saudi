# خلفيات سعودية لـ UrTV

كتالوج خلفيات من مناطق المملكة العربية السعودية، يشمل مكة والمدينة والرياض والعلا وجازان والشرقية وغيرها.

الصور من Unsplash، مع نسبها للمصورين في [PHOTO-CREDITS.md](docs/PHOTO-CREDITS.md). كل الصور في مجلد `photos/` بصيغة JPEG، وقائمة العرض في `photos/index.json`.

هذا المستودع كتالوج خلفيات مستقل. تطبيق UrTV المثبّت يحتاج تحديثاً متوافق التوقيع حتى يستخدم هذا المصدر.
